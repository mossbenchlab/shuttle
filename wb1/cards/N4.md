# Format: Weft next (block style with tables)

1. Document. A document is one value, usually a map written in block style:
- `key: value` on its own line. Keys at the same level start in the same column.
- A nested map or list goes on the following lines, indented 2 spaces more than its key (`key:` with nothing after the colon).
- A list item is a line `- value`. A list of maps can be written `- key: value` with the map's other keys on the following lines, aligned with the first key.
- Indentation uses spaces only (no tabs). Indentation decides what belongs to what.

2. Scalars.
- integer: `42`, `-7`
- string: `"text"`. Always quote strings: an unquoted word is not a string. Escapes: `\"` `\\` `\n` `\t` `\u{XXXX}`.
- boolean: `true`, `false`. null: `null` (or `nil`).
- decimal (exact; trailing zeros are kept, so 12.50m and 12.5m are different values): `12.50m`
- UTC date-time: `#2026-11-01T09:00:00Z`
- keyword (a symbolic name such as a status or a code): `:paid`

3. Lists and maps written inline (on one line, inside a block or as a whole value).
- list: `[a, b, c]`
- map: `{key: value, other: value}`. Keys must be unique.
- Block style and inline style can be mixed; inline values can nest.

4. Multi-line text. `key: |` followed by the lines of text, each indented 2 spaces more than the key; the text ends with a line break. Use `key: |-` for text without the final line break. An ordinary string with `\n` is also fine.

5. Comments. `;` or `# ` (hash and space) starts a comment to the end of the line.

6. Tables (optional). A list of maps that all have the same keys may be written as a table:
- `key: table(col1, col2, col3)` and then one row per line, indented 2 spaces more than the key. A row lists the values in column order, separated by spaces (commas are also allowed). Each row becomes a map with the column names as keys.
- A column whose values are lists of maps with the same keys is declared as `col: table(a, b)` in the header, and in a row it is written `[[a1 b1] [a2 b2]]` (one bracket per inner map, `[]` for none).
- A table with no rows is an empty list. `table(` is used only for this.

7. Example.
```
active: true
id: 7
items: table(price, qty, sku)
  3.00m 2 :p1
  0.75m 5 :p2
  19.99m 1 :p3
manager: nil
name: "Ada \"Lin\""
note: |
  first line
  second line
price: 12.50m
since: #2026-11-01T09:00:00Z
status: :paid
tags: [:vip, :east]
```
